How to get your Timeline file
How to get your Timeline file
  1. Open your phone’s Settings, then Location.
  2. Select Location services, then Timeline.
  3. Tap Export Timeline data, then Continue.
  4. Choose where to save the JSON file, tap Save, then return here.
Google’s export guide
  1. Open Google Maps and tap your profile picture.
  2. Open Settings, then Location & Privacy (formerly Personal content).
  3. Select Export Timeline data.
  4. Choose Save to Files, select a folder and save. Return here with location-history.json or Timeline.json.
