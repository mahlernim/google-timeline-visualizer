# Timeline Visualizer 1.8.0

- Select a journey across year boundaries with separate start and end years.
- Automatically reopen the most recently used Timeline file when Android retains access.
- See an active loading indicator while large Timeline files are read and prepared.
- Keep the complete route below the title card in the final journey overview.
- Use that final overview as the thumbnail for every newly created video.
- Save or share the final overview as a clear 1080 × 1080 PNG.
- Use Timeline Visualizer throughout the app and generated media in Japanese.

# 타임라인 비주얼라이저 1.8.0

- 시작 연도와 종료 연도를 따로 선택해 연도를 넘는 여행 기간을 만들 수 있습니다.
- Android가 접근 권한을 유지하면 최근 Timeline 파일을 다음 실행 때 자동으로 다시 엽니다.
- 큰 Timeline 파일을 읽고 준비하는 동안 움직이는 진행 표시를 보여 줍니다.
- 마지막 전체 경로가 제목 카드 아래의 보이는 지도 영역 안에 들어갑니다.
- 새로 만든 영상의 미리보기 이미지로 마지막 전체 경로 화면을 사용합니다.
- 마지막 전체 경로를 1080 × 1080 PNG로 저장하거나 공유할 수 있습니다.
- 앱과 생성 미디어 전반에서 일본어를 사용할 수 있습니다.

# タイムライン ビジュアライザー 1.8.0

- 開始年と終了年を個別に選び、年をまたぐ旅行期間を作成できます。
- Androidがアクセスを保持している場合、前回のTimelineファイルを次回起動時に自動で開きます。
- 大きなTimelineファイルの読み込み中に、動きのある進行表示を確認できます。
- 最後の全経路がタイトルカードの下にある表示領域へ収まります。
- 新しく作成した動画では、最後の全経路画面をサムネイルに使用します。
- 最後の全経路を1080 × 1080のPNGとして保存または共有できます。
- アプリと生成メディア全体で日本語を使用できます。
