# Timeline Visualizer 3.0.16

- Added Indonesian and Vietnamese throughout the Android app and web app, with consistent Google Maps Timeline terminology and localized import, preview, export, and settings guidance.
- Language and distance-unit controls show the detected defaults directly. You can change either selection without a separate automatic option.
- The web landing page now has a Share app button and a social link preview card.

[Get it on Google Play](https://play.google.com/store/apps/details?id=dev.mahlernim.timelinevisualizer). Play availability depends on review, country, and device. The GitHub APK is available under **Assets** below.
