# Trips Lab 4

An internal experiment focused on a simpler real-world Trips and Recaps workflow.

- Treats the imported Timeline file as one master data source managed in Settings.
- Offers Trip, Recap, Custom recap, and Raw data creation paths.
- Adds focused monthly, yearly, and exact-date controls with suggested titles.
- Adds project editing and deletion from each Library card.
- Adds a bottom action for deleting all Library content without deleting Timeline data, presets, or settings.
- Removes the arbitrary Add videos action while preserving older unassigned videos.

This prerelease upgrades Trips Lab 3, remains outside Google Play, and is not merged into the production branch.
