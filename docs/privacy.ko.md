미리보기와 MP4 영상을 기기 안에서 생성합니다.

## 앱이 접근하지 않는 정보

- 현재 위치 또는 백그라운드 위치
- Google 계정과 연락처
- 선택하지 않은 파일과 폴더
- 광고 식별자와 분석 데이터

앱은 위치, Google 로그인, 전체 저장공간 권한을 요청하지 않습니다. JSON과 영상
파일은 Android 시스템 파일 선택기를 통해 사용자가 직접 선택합니다.

## 지도 타일 요청

배경 지도를 표시하기 위해 CARTO 서버에서 OpenStreetMap 기반 지도 타일을 받습니다.
이 요청에는 선택한 타임라인 지역을 나타내는 타일 번호와 IP 주소, 사용자 에이전트
같은 일반적인 네트워크 정보가 포함됩니다. 따라서 타임라인에 포함된 지역이 CARTO에
알려질 수 있습니다. 앱은 첫 타임라인을 불러오기 전에 이 전송을 설명하고 사용자가
취소할 수 있도록 합니다. 전체 Timeline JSON, 전체 이동 경로, 제목, 영상 프레임,
완성된 영상은 CARTO나 개발자에게 전송되지 않습니다.

앱의 모든 네트워크 요청은 암호화된 HTTPS 연결을 사용합니다. CARTO는 자체 개인정보
처리방침에 따라 네트워크 및 지도 타일 요청 정보를 처리할 수 있습니다.

불러온 JSON 자체는 앱 전용 저장공간에 복사하지 않습니다. 영상을 만드는 동안에는
앱이 화면에 보이지 않아도 작업을 계속하고 Android가 앱 프로세스를 다시 만들 때
재시작할 수 있도록 선택한 경로 위치와 영상 설정을 앱 전용 저장공간에 임시로
보관합니다. 이 임시 데이터는 완성, 취소 또는 실패 후 삭제되며 Android 백업과
기기 전송에서 제외됩니다. 생성한 MP4는 사용자가 선택한 위치에 저장됩니다.
성공적으로 불러온 뒤에는 다음 실행 때 같은 문서를 다시 열 수 있도록 선택한 문서의
URI만 기록합니다. 다른 파일을 선택하면 이 참조가 교체되며 JSON 내용은 복제하지 않습니다.
Android 13 이상에서는 앱 밖에서도 진행률과 완성 알림을 표시하기 위해 알림 권한을
요청할 수 있습니다. 거부해도 영상 만들기는 계속되며 개인정보 접근 권한은 생기지
않습니다. **만든 영상** 목록을 위해 선택한 영상의 URI, 제목, 파일 이름,
영상 길이, 만든 날짜, 타임라인 기간을 앱 안에 기록하고 작은 미리보기 이미지를
앱 전용 저장공간에 보관합니다. 사용자가 직접 만들거나 추가한 MP4에만 지속적인 접근
권한을 요청합니다.
새로 만든 영상에는 마지막 전체 경로 화면으로 만든 작은 미리보기 이미지를 사용합니다.
완료 화면에서 저장하거나 공유할 수 있도록 1080 × 1080 PNG가 앱 캐시에 임시로 남을 수
있습니다. 사용자가 저장 위치를 선택하지 않으면 일반 저장공간에 PNG를 만들지 않습니다.

만든 영상 목록과 미리보기 이미지는 Android 백업과 기기 전송에서 제외되어 다른
기기로 복사되지 않습니다.

앱의 저장공간을 지우거나 앱을 삭제하면 만든 영상 목록과 미리보기 이미지도 삭제되지만,
사용자가 선택한 폴더의 MP4는 그대로 남습니다. **목록에서 제거**도 MP4를 삭제하지
않습니다. 실제 파일은 별도로 확인하는 **영상 파일 삭제**를 사용하거나 저장된 위치에서
직접 삭제할 수 있습니다.
