## 앱이 접근하지 않는 정보

- 현재 위치 또는 백그라운드 위치
- Google 계정과 연락처
- 선택하지 않은 파일과 폴더
- 광고 식별자와 분석 데이터

앱은 위치, Google 로그인, 전체 저장공간 권한을 요청하지 않습니다. JSON과 영상
파일은 Android 시스템 파일 선택기를 통해 사용자가 직접 선택합니다.

## 지도 타일 요청

배경 지도를 표시하기 위해 CARTO 서버에서 OpenStreetMap 기반 지도 타일을 받습니다.
이 요청에는 선택한 타임라인 지역을 나타내는 타일 번호와 IP 주소, 사용자 에이전트
같은 일반적인 네트워크 정보가 포함됩니다. 따라서 타임라인에 포함된 지역이 CARTO에
알려질 수 있습니다. 앱은 첫 타임라인을 불러오기 전에 이 전송을 설명하고 사용자가
취소할 수 있도록 합니다. 전체 Timeline JSON, 전체 이동 경로, 제목, 영상 프레임,
완성된 영상은 CARTO나 개발자에게 전송되지 않습니다.

앱의 모든 네트워크 요청은 암호화된 HTTPS 연결을 사용합니다. CARTO는 자체 개인정보
처리방침과 데이터 처리 계약에 따라 네트워크 및 지도 타일 요청 정보를 처리할 수 있습니다.
CARTO의 현행 배경 지도 이용약관에 따르면 CARTO는 개발자를 대신하여 요청 정보를 처리하고,
요청을 받을 때 IP 주소 일부를 제거한 뒤 해당 요청 기록을 미국에서 30일 동안 보관합니다.

영상 프리셋은 앱 전용 저장공간에만 보관됩니다. 기기 밖으로 공유되지 않으며 Android
백업과 기기 이전에서도 제외됩니다.

선택한 JSON 파일 자체는 앱 전용 저장공간에 복사하지 않습니다. 정상적으로 불러오면 파일에서
사용할 수 있는 이동 기록을 앱 전용 여행 기록 데이터베이스에 저장합니다. 이후 최신 파일을
가져올 때마다 상세 위치와 Timeline 기록을 누적하여 이전 경로의 상세 정보를 기기에 보존할 수
있습니다. 중복 파일이나 다른 사람의 파일을 거부하는 데 필요한 가져오기 출처 정보도 기록합니다.
이 데이터베이스는 시간에 따른 이동 기록을 한곳에 모을 수 있으므로 단일 Timeline 내보내기보다
민감합니다. Android 클라우드 백업과 기기 전송에서는 제외됩니다.

영상을 만드는 동안에는
앱이 화면에 보이지 않아도 작업을 계속하고 Android가 앱 프로세스를 다시 만들 때
재시작할 수 있도록 선택한 경로 위치와 영상 설정을 앱 전용 저장공간에 임시로
보관합니다. 이 임시 데이터는 완성, 취소 또는 실패 후 삭제되며 Android 백업과
기기 전송에서 제외됩니다. Android 10 이상에서는 생성한 MP4를 `Movies/Timeline Visualizer`에 자동 저장하고 Android 8과 9에서는 시스템 저장 창을 사용합니다.
성공적으로 불러온 뒤에는 다음 실행 때 같은 문서를 다시 열 수 있도록 선택한 문서의
URI도 기록합니다. 다른 파일을 선택하면 이 참조가 교체됩니다.
Android 13 이상에서는 앱 밖에서도 진행률과 완성 알림을 표시하기 위해 알림 권한을
요청할 수 있습니다. 거부해도 영상 만들기는 계속되며 개인정보 접근 권한은 생기지
않습니다. 여행 기록 알림은 선택 사항입니다. 사용하면 로컬 백그라운드 작업이 여행 기록의
최신 상태 메타데이터만 확인하고, 최신 Timeline 내보내기로 최근 경로 상세 정보를 보존할 시점에
한두 차례 조용한 알림을 표시할 수 있습니다. 원본 문서를 다시 열거나 기기 위치를 사용하거나
개발자 서버에 연결하지 않습니다. 알림 설정은 기기에만 저장되고 Android 백업과 기기 전송에서
제외됩니다. **영상** 목록을 위해 선택한 영상의 URI, 제목, 파일 이름,
영상 길이, 만든 날짜, 타임라인 기간을 앱 안에 기록하고 작은 미리보기 이미지를
앱 전용 저장공간에 보관합니다. 사용자가 직접 만들거나 추가한 MP4에만 지속적인 접근
권한을 요청합니다.
새로 만든 영상에는 마지막 전체 경로 화면으로 만든 작은 미리보기 이미지를 사용합니다.
완료 화면에서 저장하거나 공유할 수 있도록 1080 × 1080 PNG가 앱 캐시에 임시로 남을 수
있습니다. 사용자가 저장 위치를 선택하지 않으면 일반 저장공간에 PNG를 만들지 않습니다.

영상 목록과 미리보기 이미지는 Android 백업과 기기 전송에서 제외되어 다른
기기로 복사되지 않습니다.

Android의 **설정 → 앱 → Timeline Visualizer → 저장공간 및 캐시 → 캐시 삭제**를 사용하면
지도 타일을 비롯한 임시 파일을 삭제할 수 있습니다. 캐시를 삭제해도 여행 기록은 삭제되지
않습니다. **저장공간 삭제**를 사용하거나 앱을 삭제하면 여행 기록, 알림 메타데이터, 영상 목록,
미리보기 이미지와 기타 모든 앱 전용 데이터가 삭제됩니다. 원본 Timeline 기록을 다시 가져올 수
없는 경우 삭제된 여행 기록은 복구할 수 없습니다. 공용 Movies 폴더의 MP4는 그대로 남습니다.
**목록에서 제거**도 MP4를 삭제하지
않습니다. 실제 파일은 별도로 확인하는 **영상 파일 삭제**를 사용하거나 저장된 위치에서
직접 삭제할 수 있습니다.

배경 지도 타일은 앱의 비공개 임시 캐시에 최대 30일 동안만 남으며, 그보다 오래된 타일은
앱이 자동으로 삭제합니다.
