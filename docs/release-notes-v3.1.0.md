## Install or use Timeline Visualizer

- **Android:** [Install from Google Play](https://play.google.com/store/apps/details?id=dev.mahlernim.timelinevisualizer)
- **iPhone, iPad, or computer:** [Open the web app](https://ahn-lab.org/google-timeline-visualizer/). No installation is required.

# Timeline Visualizer 3.1.0

Android previews and videos now use CARTO vector maps by default. This update replaces the retiring map key with a dedicated Android key, while the web app uses its own website-restricted key.

- Keeps map attribution and adds a linked CARTO logo beside the Android preview.
- Uses OpenGL for broader device compatibility and bounds map snapshot memory for larger video formats.
- Reuses map backgrounds during camera motion and retains map resources for no more than 30 days.
- Adds localized recovery guidance. If vectors cannot load, turn off **Vector map** in Settings to use image maps.

Vector maps can change label placement and map detail. Export speed depends on the device and journey. Timeline files and video creation remain on the device.
