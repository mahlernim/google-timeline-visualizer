# Timeline Visualizer 3.0.0

Travel Journal is now the main Android experience.

- Import `Timeline.json` to build a private, on-device Journal that can grow with later exports.
- Videos automatically use detailed route observations where available and Timeline history for gaps.
- Find trips, save projects, create monthly or yearly recaps, and reuse preserved route detail.
- Optional quiet reminders help preserve recent detail before it disappears from later exports.
- Long route preparation now shows its current phase after a short wait.
- Close-up camera timing gives meaningful local arrivals more room while keeping the total adjustment bounded.

The selected JSON file and Travel Journal are never uploaded. The Journal is excluded from Android backup and device transfer. Clearing app storage or uninstalling removes it.

Existing Timeline Visualizer installations upgrade in place. Import `Timeline.json` once to create the new Travel Journal.
