# Indonesian localization

The Indonesian catalog uses the `values-in` Android legacy qualifier and `id-ID` for the Google Play listing. Indonesian has one Android plural quantity here, `other`.

## Terminology decisions

| English | Indonesian used | Reason |
| --- | --- | --- |
| Timeline | Linimasa | Google Maps Indonesian Help calls the feature `Linimasa`. |
| Location services | Layanan lokasi | Matches the Android export path in the Indonesian Google Maps guide. |
| Export Timeline data | Ekspor data Linimasa | Official Google Maps menu wording. |
| Files | File | Apple Indonesian documentation calls the app `File`. |
| Save to Files | Simpan ke File | Used for the iPhone export instruction. |

The catalog retains `Timeline.json`, `location-history.json`, JSON, MP4, CARTO, and `semanticSegments` unchanged because they are filenames, formats, service names, or schema fields.
