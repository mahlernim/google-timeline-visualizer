# Trips Lab 1

An experimental, separately installed build for testing a Trips and Recaps workspace.

- Imports or updates a Timeline file and suggests likely multi-day trips locally.
- Keeps confirmed trips and recaps when the Timeline file changes.
- Shows two suggestions first, with an option to show all.
- Supports monthly and yearly recaps.
- Guides creation through project details, a video preset, preview, and generation.
- Groups generated videos under their trip or recap.

This prerelease uses a separate package and app data from Timeline Visualizer. It is not distributed through Google Play.
