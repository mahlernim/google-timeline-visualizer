# Timeline Visualizer 2.4.2

Restored map backgrounds after CARTO began requiring authenticated basemap
requests. Official Android and web releases now use the project's CARTO key, and
Android automatically removes cached map tiles after 30 days.

## 한국어

복구했습니다. 공식 Android 및 웹 릴리스는 이제 프로젝트의 CARTO 키를 사용하며,
Android는 캐시된 지도 타일을 30일 후 자동으로 삭제합니다.
