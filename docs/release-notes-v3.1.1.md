## Install or use Timeline Visualizer

- **Android:** [Install from Google Play](https://play.google.com/store/apps/details?id=dev.mahlernim.timelinevisualizer)
- **iPhone, iPad, or computer:** [Open the web app](https://ahn-lab.org/google-timeline-visualizer/). No installation is required.

# Timeline Visualizer 3.1.1

Choose **Trip time zone** in the Android trip details screen to keep visits on the correct calendar day when you create a video after returning home. The date picker, preview, and exported video use the same zone. Saved trips and resumed exports remember your choice.
