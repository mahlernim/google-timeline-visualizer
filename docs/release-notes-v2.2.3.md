# Timeline Visualizer 2.2.3

Timeline exports containing only raw location data can now be opened as an optional
fallback. The app warns that the route and distance may be inaccurate and recommends
confirming or restoring Timeline in Google Maps before exporting again. If you continue,
the app reduces noise with an accuracy limit and short impossible-jump rejection while
keeping the original coordinates unchanged. Raw location data in mixed exports remains
optional. Thanks to `@PeaShooterR` for contributing the original raw location import mode
in PR #84.
