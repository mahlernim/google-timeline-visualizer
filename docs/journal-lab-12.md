# Journal Lab 12

This side build makes long first-time journey preparation easier to understand and preserves more useful route shape in semantic-only history.

- Create choices remain available while journeys are prepared in the background.
- A compact progress row shows real preparation stages without extra Timeline queries, point counting, or estimated completion times.
- Detailed routes remain canonical.
- Semantic-only periods prefer useful path detail and suppress only high-confidence competing duplicate histories.
- Prepared journeys remain cached locally, and updated imports rebuild only the affected route window.
- Timeline files and the Travel Journal remain on the device.

Journal Lab installs separately from the main Timeline Visualizer app.
