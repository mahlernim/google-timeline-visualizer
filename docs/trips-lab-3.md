# Trips Lab 3

An internal experiment for testing a clearer Trips and Recaps workflow.

- Separates the saved Library from trip and recap creation.
- Starts Create by asking for a Trip video or Recap video.
- Shows approximate movement coverage before a trip is selected.
- Uses exact dates for trips and calendar labels for matching recaps.
- Removes the unclear static route-lines graphic.
- Returns from video customization to the same Create draft.

This prerelease uses the Trips Lab package, upgrades Trips Lab 2, and is not distributed through Google Play.
