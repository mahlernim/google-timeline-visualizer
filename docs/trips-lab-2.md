# Trips Lab 2

An experimental update for testing a Trips and Recaps focused workflow.

- Finds possible trips only when requested for a selected year or date range.
- Includes outbound and return travel dates and suggests an offline destination name.
- Uses a three-step creation flow for project details, video style, and preview.
- Includes Trip Close-up and Recap Portrait presets with duration settings.
- Groups distinguishable video versions under each trip or recap.
- Adds play, share, settings details, and permanent deletion for individual videos.
- Preserves Trips Lab 1 trips, presets, Timeline references, and video associations on upgrade.

This prerelease uses the Trips Lab package and is not distributed through Google Play.
