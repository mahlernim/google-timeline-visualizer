# Vietnamese localization

## Terms

| English | Vietnamese |
| --- | --- |
| Timeline | Dòng thời gian |
| Travel Journal | Nhật ký Du lịch |
| Export Timeline data | Xuất dữ liệu trên Dòng thời gian |
| Location services | Dịch vụ vị trí |
| Save to Files | Lưu vào Tệp |

Google Maps Android terminology follows [Google Maps Help in Vietnamese](https://support.google.com/maps/answer/6258979?co=GENIE.Platform%3DAndroid&hl=vi). Its export path is Cài đặt, Vị trí, Dịch vụ vị trí, Dòng thời gian, then Xuất dữ liệu trên Dòng thời gian.

The iPhone instruction uses Apple’s Vietnamese label “Lưu vào Tệp”, documented in [Apple Support](https://support.apple.com/vi-vn/guide/iphone/ipha9ed5131c/ios). Product names, filenames, JSON, MP4, H.264, CARTO, Google Maps, Android and iPhone remain unchanged.
