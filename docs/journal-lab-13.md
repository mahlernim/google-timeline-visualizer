# Journal Lab 13

This side build prepares only the journey range needed for the video you choose.

- Trip, Recap, and Custom appear as soon as Journal metadata is ready.
- Opening Create no longer reconstructs the complete lifetime Journal route.
- Recaps, custom ranges, manual trips, saved trips, and trip detection load only their requested dates.
- A prepared year can immediately serve a trip inside that year.
- Long-running preparation keeps the compact staged progress indicator.
- Updated imports invalidate only affected cached coverage.
- Detailed routes remain canonical and Journey history fills uncovered periods.
- Timeline files and the Travel Journal remain on the device.

Journal Lab installs separately from the main Timeline Visualizer app.
