# Timeline Visualizer 3.0.2

A small fix release for raw-signal videos.

- Raw-signal videos no longer draw impossible detours. When several consecutive readings shared the same wrong location, the filter kept them all; it now removes the whole cluster.
- Korean now uses one word for video throughout the app.

Your Travel Journal, your Timeline file, and your saved videos are unchanged.
