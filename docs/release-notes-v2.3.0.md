# Timeline Visualizer 2.3.0

Camera controls are now clearer and better organized. Choose an aspect ratio, zoom
style, long-trip detection, local trip framing, and long-trip pacing as one coherent
set of video defaults. Export resolution, regional preferences, and Timeline cleanup
now have separate sections.

Long journeys also benefit from the Camera Lab results, including earlier destination
framing, grouped long transfers, and improved pacing. The experimental zoom slowdown
was removed.
