# Google 타임라인 비주얼라이저

[English](README.md) · [日本語](README.ja.md)

Google 지도 타임라인 내보내기 파일로 여행 경로 영상을 만드는 Android 앱입니다.
연도 또는 월 범위를 선택하고 미리 본 뒤, 공유하기 좋은 MP4로 저장할 수 있습니다.
JSON 파일과 영상 렌더링은 휴대전화 안에서 처리됩니다.

## Android에 설치하기

아직 Google Play에는 등록되지 않았습니다. 이 저장소의
[최신 릴리스](https://github.com/mahlernim/google-timeline-visualizer/releases/latest)에서 설치하세요.

1. **Assets**에서 `TimelineVisualizer-v1.8.0.apk`를 휴대전화로 다운로드합니다.
2. 다운로드한 파일을 엽니다.
3. 설치가 차단되면 **설정**을 누르고, 사용한 브라우저 또는 파일 앱의
   **출처를 알 수 없는 앱 설치**를 허용한 뒤 다시 설치합니다.
4. 설치가 끝나면 이 권한을 다시 꺼도 됩니다.

반드시 이 저장소에서만 APK를 받으세요. Google Play 외부에서 직접 설치하기 때문에
Android가 경고를 표시할 수 있으며, 이는 정상입니다. Android 8.0 이상이 필요합니다.
이 릴리스 이후 버전은 기존 앱 위에 업데이트로 설치할 수 있습니다.

## Timeline.json 내보내기

Android에서는 Google 지도 앱이 아니라 **휴대전화 설정**에서 내보냅니다.

1. **휴대전화 설정**을 엽니다.
2. **위치 → 위치 서비스 → 타임라인**으로 이동합니다.
3. **타임라인 데이터 내보내기**를 선택하고 계속 진행합니다.
4. `Timeline.json`을 **다운로드**처럼 찾기 쉬운 폴더에 저장합니다.

타임라인 메뉴가 없거나 이름이 다르면 [Google 타임라인 도움말](https://support.google.com/maps/answer/6258979)을
확인하세요.

제조사와 Android 버전에 따라 메뉴 이름이나 위치가 조금 다를 수 있습니다. 앱의
**JSON 받기** 버튼에서 이 안내를 다시 볼 수 있고 위치 설정 화면도 열 수 있습니다.
다만 Android에는 타임라인 화면까지 바로 여는 표준 링크가 없습니다.

iPhone에서는 **Google 지도 → 프로필 사진 → 설정 → 개인 콘텐츠 → 타임라인 데이터
내보내기**를 사용한 뒤 JSON 파일을 Android 휴대전화로 옮기세요.

## 영상 만들고 공유하기

1. **타임라인 불러오기**를 누르고 내보낸 파일을 선택합니다.
2. 시작 연도와 월, 종료 연도와 월을 선택합니다. 기본값은 최신 전체 연도이며,
   연도를 넘는 기간도 선택할 수 있습니다.
3. 영상에 표시할 이름과 제목 템플릿을 확인하고 15, 30, 45, 60, 75, 90초 중
   이동 재생 길이를 선택합니다. `{year}`와 `{name}`을 사용할 수 있으며 입력한
   템플릿은 다음에도 유지됩니다.
4. **미리보기**로 움직이는 지도를 확인합니다. 저장 영상도 같은 디자인을 사용하지만,
   지도를 먼저 준비한 뒤 안정적으로 렌더링합니다.
5. **영상 만들기**를 누르고 저장 위치를 선택합니다. 단계별 진행률과 예상 남은 시간이
   표시되며, 만드는 도중 취소할 수도 있습니다. 다른 앱으로 전환하거나 화면을 꺼도
   영상 만들기는 계속됩니다.
6. 완성되면 영상을 보거나 공유하고, 1080 × 1080 전체 경로 이미지를 저장하거나
   공유한 뒤 다른 영상을 만들 수 있습니다.

타임라인을 성공적으로 불러오면 저장소가 접근 권한을 유지하는 경우 다음 실행 때 같은
문서를 자동으로 다시 엽니다. 타임라인 데이터는 복사하지 않습니다. 파일이 이동되었거나
권한이 사라지면 일반 불러오기 화면으로 안전하게 돌아갑니다.

오래된 이동 경로는 위치 마커 뒤에서 점차 사라지므로 위치가 많은 타임라인도 깔끔하고
효율적으로 영상으로 만들 수 있습니다. 선택한 이동 재생이 끝나면 1.5초 동안 전체
경로로 부드럽게 축소하고, 완성된 지도를 0.5초간 보여 줍니다.

취소하면 완성되지 않은 파일은 삭제됩니다. 미리보기가 끝난 뒤 다시 누르면 처음부터
재생됩니다. Android 13 이상에서는 알림을 허용하면 앱 밖에서도 진행률을 확인하고
완성 알림을 받을 수 있습니다. 알림을 허용하지 않아도 영상 만들기는 계속됩니다.

## 만든 영상 보관하기

완성된 영상은 **만든 영상** 목록에 자동으로 추가됩니다. 미리보기 이미지, 제목,
타임라인 기간, 영상 길이, 만든 날짜를 확인하고 바로 보거나 공유할 수 있습니다.
MP4는 사용자가 선택한 폴더에 그대로 두며, 앱에는 작은 목록 정보와 미리보기 이미지만
저장합니다.

이 기능을 추가하기 전에 만든 MP4는 **영상 추가**로 가져올 수 있습니다. 여러 영상을
한 번에 선택할 수도 있습니다. 앱 밖에서 파일을 옮기거나 삭제하면 **파일을 찾을 수
없음**으로 표시되며, 필요할 때 목록에서 제거할 수 있습니다.

**목록에서 제거**는 MP4 파일을 지우지 않습니다. **영상 파일 삭제**는 별도의 확인을
거친 뒤 저장된 파일을 완전히 삭제합니다. 앱 아래쪽의 **업데이트 확인**을 누르면 설치한
버전에 맞는 공식 업데이트 페이지가 열립니다. **GitHub 프로젝트**는 소스 코드 링크입니다.

장거리 비행처럼 중간 위치가 없는 구간도 대권 경로를 따라 부드럽게 보간합니다.
따라서 카메라가 목적지로 갑자기 건너뛰지 않고 중요한 장거리 이동을 따라갑니다.
가까운 거리를 이동할 때는 마커가 화면 중앙의 안정 영역 안에서 움직인 뒤 카메라가
따라갑니다. 타임라인 위치를 변경하거나 제거하지 않으면서 출퇴근 경로에서 지도가
앞뒤로 빠르게 흔들리는 현상을 줄였습니다.

## 개인정보 보호

Google 로그인, 위치 권한, 계정 권한, 분석 도구, 전체 저장공간 권한을 사용하지
않습니다. 사용자가 직접 선택한 JSON과 영상 파일만 읽습니다.

Google 로그인으로 프로필 이름을 얻을 수는 있지만 휴대전화에 저장된 타임라인 기록을
가져올 수는 없습니다. 내보내기 단계를 줄이지 못하면서 계정 권한만 추가되므로,
기본 제목에는 사용자가 수정할 수 있는 휴대전화 이름을 사용합니다.

네트워크는 배경 지도에만 사용됩니다. CARTO에는 화면에 표시할 지도 영역의 타일 요청이
전송되지만 Timeline JSON은 업로드되지 않습니다. 첫 타임라인을 불러오기 전에 앱이
이 전송을 설명하고 취소할 수 있도록 합니다. 자세한 내용은
[개인정보 보호 안내](docs/privacy.ko.md)를 확인하세요.

## 지원 형식

- 최신 Android/iOS 타임라인 내보내기
- 이전 `semanticSegments` 형식
- 이동 경로, 활동, 방문 위치
- 문자열, `latLng`, 도(°), `geo:`, E7 좌표
- 날짜 변경선을 지나는 경로

원본 Python 데스크톱 버전도 계속 제공됩니다. 이 프로젝트는
