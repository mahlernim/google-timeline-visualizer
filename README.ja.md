# Google タイムライン ビジュアライザー

[English](README.md) · [한국어](README.ko.md)

Google マップから書き出したTimeline.jsonを使って、Android端末内で旅行経路の動画と全経路画像を作成します。JSONと動画の処理は端末内で行われます。

## Androidへのインストール

このリポジトリの[最新リリース](https://github.com/mahlernim/google-timeline-visualizer/releases/latest)から`TimelineVisualizer-v1.8.0.apk`をダウンロードしてください。Android 8.0以降が必要です。

## Timeline.jsonの書き出し

Androidでは、端末の設定から**位置情報 → 位置情報サービス → タイムライン → タイムライン データのエクスポート**を開きます。項目名は端末によって異なる場合があります。

iPhoneでは、**Google マップ → プロフィール写真 → 設定 → 個人的なコンテンツ → タイムライン データのエクスポート**を使用します。

## 動画と全経路画像を作成する

1. **タイムラインを読み込む**を選び、Timeline.jsonを指定します。対応する保存先では、次回起動時に同じファイルを自動で開きます。
2. 開始年、開始月、終了年、終了月を選びます。年をまたぐ期間にも対応します。
3. 名前、タイトルテンプレート、動画時間を確認します。`{year}`は選択した年の範囲、`{name}`は名前に置き換わります。
4. **プレビュー**で確認し、**動画を作成**からMP4の保存先を選びます。
5. 完成後は動画の再生や共有に加え、1080 × 1080の全経路PNGを保存または共有できます。

最後の全経路画面では、タイトルの下にある表示領域へ経路全体が収まります。作成した動画のサムネイルにも同じ画面を使用します。

## プライバシー

Googleログイン、位置情報権限、分析機能、ストレージ全体へのアクセスは使用しません。背景地図のため、表示地域のタイル座標と通常のネットワーク情報だけがCARTOへ送信されます。Timeline.jsonはアップロードされません。詳しくは[プライバシー説明](docs/privacy.ja.md)をご覧ください。
